# SNAD Heatmap Paper

## USAGE:
Set your working directory to the Code folder, and the scripts will run smoothly.
You will need the following file set up to use the script files as they are currently set up:

Parent folder (any name)
-> Code
-> Data
	-> Data/raw and intermediate
-> Output
	-> Output/Figures
	-> Output/Tables
		-> Output/Tables/raw

## REPOSITORY RULES: 
1. The git repository should be set to the Code folder. 
2. Do not add or push any data files to git for data protection reasons. There is a currently a .gitignore set up in the repository designed to prevent this, but be careful anyway.
